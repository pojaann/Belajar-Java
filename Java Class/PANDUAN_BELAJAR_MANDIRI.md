# Panduan Belajar Java Mandiri

Panduan ini membantu kamu belajar sedikit demi sedikit menggunakan file latihan di folder ini. Tidak perlu terburu-buru: pahami satu topik, coba sendiri, lalu lanjutkan.

Setiap topik memiliki file `Latihan...java` yang kosong untuk kamu isi sendiri. File `Topik...java` berisi contoh jadi yang bisa dibaca setelah kamu mencoba, atau digunakan untuk membandingkan hasil.

## Cara menggunakan setiap file

Untuk setiap topik:

1. Baca komentar dan kode dari atas ke bawah.
2. Sebelum menekan **Run**, tebak dulu apa yang akan tampil.
3. Jalankan program di VS Code dan bandingkan hasilnya dengan tebakanmu.
4. Ubah beberapa nilai atau baris kode, simpan, lalu jalankan lagi.
5. Kerjakan bagian `Latihan` di akhir file tanpa melihat contoh lain terlebih dahulu.
6. Jika muncul error, baca pesan error dari baris pertama. Periksa nama file, nama `public class`, tanda kurung, dan titik koma.

Jalankan program dengan membuka file Java yang ingin dicoba, lalu klik **Run** di atas method `main`. Untuk program yang meminta input, ketik jawaban di Terminal.

> Nama file Java harus sama dengan nama `public class` di dalamnya. Contoh: `Topik01HelloWorld.java` berisi `public class Topik01HelloWorld`.

## Rencana belajar

Satu sesi dapat berlangsung sekitar 25–45 menit. Ulangi atau perpanjang sesi sesuai kebutuhan.

### Sesi 1 — Output dan komentar

Buka [Latihan01HelloWorld.java](./Latihan01HelloWorld.java) dan tulis program pertamamu. Jika perlu melihat contoh setelah mencoba, buka [Topik01HelloWorld.java](./Topik01HelloWorld.java).

- Pahami perbedaan `print` dan `println`.
- Ubah teks yang dicetak dan tambahkan komentar.
- **Target:** dapat menjelaskan fungsi `main` dan menampilkan beberapa baris teks.

### Sesi 2 — Variabel dan tipe data

Buka [Latihan02Variabel.java](./Latihan02Variabel.java). Contoh jadi: [Topik02Variabel.java](./Topik02Variabel.java).

- Coba `String`, `int`, `double`, `boolean`, dan `char`.
- Coba operator `+`, `-`, `*`, `/`, dan `%`.
- **Target:** dapat memilih tipe data sederhana dan menghitung nilai.

### Sesi 3 — Input pengguna

Buka [Latihan03InputScanner.java](./Latihan03InputScanner.java). Contoh jadi: [Topik03InputScanner.java](./Topik03InputScanner.java).

- Masukkan nama dan umur yang berbeda saat program meminta input.
- Coba tambahkan pertanyaan dan tampilkan jawabannya.
- **Target:** dapat membaca teks dan bilangan bulat dari pengguna.

### Sesi 4 — Kondisi

Buka [Latihan04Kondisi.java](./Latihan04Kondisi.java). Contoh jadi: [Topik04Kondisi.java](./Topik04Kondisi.java).

- Uji beberapa nilai: di bawah batas, tepat pada batas, dan di atas batas.
- Perhatikan penggunaan `>=`, `<=`, `||`, dan `else`.
- **Target:** dapat membuat program memilih tindakan berdasarkan nilai.

### Sesi 5 — Perulangan

Buka [Latihan05Perulangan.java](./Latihan05Perulangan.java). Contoh jadi: [Topik05Perulangan.java](./Topik05Perulangan.java).

- Ubah nilai awal, batas, dan perubahan angka pada perulangan.
- Pastikan `while` memiliki perubahan yang membuat kondisinya akhirnya salah.
- **Target:** dapat mencetak urutan angka dan mengenali risiko perulangan tanpa akhir.

### Sesi 6 — Method

Buka [Latihan06Method.java](./Latihan06Method.java). Contoh jadi: [Topik06Method.java](./Topik06Method.java).

- Ubah parameter yang diberikan ke method.
- Buat method baru yang melakukan perhitungan sederhana.
- **Target:** dapat membuat method dengan parameter dan nilai kembalian.

### Sesi 7 — Array

Buka [Latihan07Array.java](./Latihan07Array.java). Contoh jadi: [Topik07Array.java](./Topik07Array.java).

- Tambah atau ubah elemen array.
- Perhatikan bahwa indeks dimulai dari `0`.
- Coba hitung total atau rata-rata dari kumpulan angka.
- **Target:** dapat menyimpan dan memproses beberapa nilai sejenis.

### Sesi 8 — Class dan object

Buka [Latihan08ClassObject.java](./Latihan08ClassObject.java). Contoh jadi: [Topik08ClassObject.java](./Topik08ClassObject.java).

- Buat object dengan data berbeda.
- Tambahkan satu field baru dan tampilkan nilainya.
- **Target:** memahami bahwa class adalah cetak biru dan object adalah hasil pembuatannya.

## Proyek latihan akhir

Buat file baru bernama `ProyekNilaiSiswa.java`, lalu buat program yang:

1. Meminta nama siswa.
2. Meminta tiga nilai angka.
3. Menghitung rata-rata.
4. Menampilkan nama, rata-rata, dan hasil lulus atau perlu belajar lagi.
5. Menggunakan setidaknya satu method buatan sendiri.

Petunjuk: gabungkan `Scanner`, variabel, kondisi, dan method. Kerjakan dulu dengan kemampuanmu sendiri; lihat file topik hanya jika perlu mengingat sintaks.
